공용 규칙

  • 포인트 컬러는 --accent 하나만 씁니다. 상태색(--ok·--warn·--danger)은 상태 표시에만 씁니다.
  • UI에 이모지를 쓰지 않습니다. 아이콘은 ui.js 의 인라인 SVG(선 1.75px)를 씁니다.
  • 여백(padding·margin·gap)은 --sp-숫자 토큰만 씁니다(숫자 = px). 4px 단위가 기본이고 2px 단위는 세밀한 맞춤용입니다.
  • 숫자(가격·시간·인원)에는 .num(고정폭 숫자)을 붙입니다. 페이지 제목·모임 이름은 .heading(Pretendard 800). 로고는 SVG(TT.LOGO_SVG, core.js).
  • CSS 파일에는 색·반경·글자 크기·z-index·여백 값을 직접 쓰지 않고 토큰을 씁니다. npm test 가 검사합니다. 전체 규칙은 .agents/AGENTS.md 의 "디자인 작업 규칙".
